## 품질 게이트

- [x] 1×(48×48)에서 큰 별 모자, 고글, 짧은 망토, 부츠 실루엣이 구분됩니다.
- [x] 2×(96×96)과 4×(192×192)에서 최근접 이웃 확대가 적용되어 픽셀 경계가 흐려지지 않습니다.
- [x] 배경 알파는 완전 투명이고 캐릭터 픽셀은 완전 불투명해 반투명 테두리가 없습니다.
- [x] 보이는 픽셀은 23색으로 제한되어 레트로 팔레트가 유지됩니다.
- [x] 캐릭터 발끝이 48×48 캔버스의 아래쪽 기준선에 닿고 몸체가 가로 중앙에 배치됩니다.
- [x] 노랑·청록·크림·코랄·짙은 남색 계열이 문서의 공통 스타일 잠금과 일치합니다.
- [x] 기존 상용 게임 캐릭터의 고유 실루엣·복장·로고를 복제하지 않은 독창적인 디자인입니다.
- [x] 글자, 숫자, 로고, 워터마크, 배경 장면, 추가 캐릭터가 없습니다.
