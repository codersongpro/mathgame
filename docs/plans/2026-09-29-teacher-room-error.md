# 교사 방 생성 오류 안내 개선

## 확인한 현상

- 배포된 교사 화면에서 의도적으로 틀린 키를 입력해도 키 오류 대신 일반적인 방 생성 실패 메시지가 표시됐다.
- 현재 웹 API는 Worker가 반환한 401을 제외한 모든 오류를 같은 메시지로 바꾼다.
- 실제 Worker의 설정 누락 여부와 배포 상태는 아직 확인되지 않았다. 이 변경은 원인을 감추지 않는 진단 개선이며 운영 설정 수정의 대체물이 아니다.

## 구현 계획

1. Worker의 `CONFIG_MISSING`(503), 404, 401 응답에 대한 웹 API 테스트를 먼저 작성한다.
2. 비밀키·Worker 원문 응답은 노출하지 않고, 확인할 설정을 알려주는 메시지만 반환한다.
3. 교사 API 단위 테스트와 웹 타입 검사를 실행한다. 배포·원격 푸시는 하지 않는다.

## 완료 기준

- 키 오류, Cloudflare 교사 키 설정 누락, Worker 배포 버전 불일치를 화면에서 구분할 수 있다.
- 교사 토큰은 기존처럼 HttpOnly 쿠키에만 보관된다.
