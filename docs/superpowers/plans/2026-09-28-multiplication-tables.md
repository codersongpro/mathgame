# Bubble Semble 페이즈 3-5: 교사 선택형 1~19단

## 짧은 요약

교사가 방을 열 때 1~19단 중 여러 단을 고르면 그 방의 일반 문제와 협동 관문 문제에 선택한 단의 곱셈을 출제합니다. 선택하지 않으면 기존 20 이내 덧셈·뺄셈을 유지합니다.

## 범위와 가정

- 구구단 선택은 **방을 열 때만** 적용합니다. 진행 중 설정 변경은 학생마다 다른 문제 규칙을 만들 수 있어 이번 묶음에 넣지 않습니다.
- 한 단도 선택하지 않으면 기존 문제 유형을 유지합니다. 하나 이상 선택하면 이번 묶음에서는 선택 단의 곱셈만 출제합니다. 덧셈·뺄셈과 섞기, 학년별 난이도, 나눗셈과 수학 개념 문제는 다음 묶음에서 다룹니다.
- 각 단의 곱하는 수는 1~19에서 바뀌며, 방별 무작위 시드와 출제 순서가 문제를 결정합니다. 학생 답·정답은 방 전체나 교사 화면에 공개하지 않습니다.
- 정답 범위가 최대 361이므로 클라이언트·서버의 선택지 검증 범위를 함께 늘립니다. 학생이 보낸 임의 숫자가 정답 처리되지 않도록 서버는 현재 문제의 실제 선택지에 속하는지도 계속 검사합니다.

## 무엇을 할지 → 왜 → 어떻게 확인할지

| 단계 | 구현 | 이유 | 완료 기준 |
|---|---|---|---|
| 1 | 방 설정에 1~19단 복수선택과 검증 추가 | 교사가 수업 범위를 안전하게 지정 | 빈 선택의 기존 기본값, 여러 단, 중복·범위 밖 입력 단위 테스트 |
| 2 | 문제 생성기가 선택 단의 곱셈과 4개 선택지를 생성 | 실제 플레이와 협동 관문에 같은 수업 범위 적용 | 선택 단만 출제, 정답·선택지 유효성, 시드별 변화 테스트 |
| 3 | 교사 화면 체크박스·설정 표시, 서버 연결 | 키보드 없는 태블릿에서도 방 설정 가능 | 폼·방 생성·WebSocket 테스트, 타입 검사·빌드 |

## 배포 경계

작업 브랜치에만 반영합니다. 운영 `main`, Vercel, Cloudflare는 변경하지 않습니다.

## 구현·검증 결과

- 교사 화면에 1~19단 터치 선택을 추가하고, 빈 선택은 기존 덧셈·뺄셈으로 유지했습니다.
- 선택한 단이 개인 문제와 협동 관문 문제에 적용되며, 서버가 361까지의 현재 선택지만 정답으로 받습니다.
- 게임 코어 41개, 공유 프로토콜 16개, 실시간 서버 38개, 웹 40개 테스트가 통과했습니다. 웹·실시간 타입 검사와 웹 프로덕션 빌드도 통과했습니다.
- 실제 태블릿 수동 플레이와 운영 배포는 아직 수행하지 않았습니다.
