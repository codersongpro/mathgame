# Bubble Semble 페이즈 2-4: 학생별 수학 문제 구현 계획

## 짧은 요약

학생마다 계산 문제가 따로 보이고, 정답은 서버에서만 판정한다. 태블릿의 큰 선택 버튼으로 답하며, 교사는 학생별 정답 수만 확인한다.

## 범위와 가정

- 이번 단계의 문제는 **20 이내 덧셈·뺄셈**이다. 전 학년 개념·구구단 선택·난이도 적응은 다음 단계에서 다룬다.
- 입장 시 한 문제를 발급하고, 정답 또는 두 번 오답 후 학생이 `다음 문제`를 눌러 계속한다.
- 첫 오답에는 힌트와 한 번의 재도전 기회를 제공한다. 정답을 맞히면 짧은 시간 동안 거품 발사 간격이 줄어든다.
- 교사에게는 별명, 접속 상태, 맞힌 문제 수만 보인다. 개인 문제·오답·난이도는 공개하지 않는다.
- 새 학습 기록은 데이터베이스에 저장하지 않는다. 연결이 유지되는 동안 방의 메모리에만 두고, 재접속 시 가능한 경우 이어간다. 서버 재시작·휴면 해제 후 문제/정답 수가 초기화될 수 있다는 한계는 이번 단계에서 명시한다.

## 구현과 확인

1. 문제 규칙과 통신 형식 추가 → **확인:** 선택지 중 정답 하나, 음수 없는 문항, 답안 형식 검증, 공개 메시지에 정답 없음.
2. 실시간 서버에 학생별 문제·답안 판정 추가 → **확인:** 서로 다른 학생의 문제 격리, 첫 오답 힌트, 두 번째 오답 종료, 중복·위조 제출 거절, 재접속 동작, 정답 시 발사 강화.
3. 학생용 터치 문제창과 교사 정답 수 표시 → **확인:** 키보드 없이 선택·다음 문제 가능, 2인 같은 화면 게임 유지, 교사 화면에 문제·오답 없음.
4. 관련 테스트·타입 검사·대표 브라우저 경로 확인 → **확인:** 학생 입장→문제 풀이→교사 현황 갱신.

## 범위 밖

- 학년별 문제 은행, 1~19단 복수 선택, 나눗셈·도형 등 전 영역, 장기 성장 기록·랭크, 3+1 스테이지와 보스전.
- 개인정보 또는 학습 기록의 영구 저장. 영구 저장 시 암호화 설계를 별도로 승인받는다.
