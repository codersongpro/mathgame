# Bubble Semble 페이즈 5-1: 1·2학년 기본 계산 선택

## 짧은 요약

교사가 방을 열 때 1학년 또는 2학년 기본 계산을 선택합니다. 구구단을 별도로 선택하지 않은 방에서 1학년은 기존 20 이내 덧셈·뺄셈, 2학년은 100 이내 덧셈·뺄셈을 출제합니다.

## 가정과 경계

- 기본값은 1학년으로 하여 기존 방의 문제 난이도를 바꾸지 않습니다.
- 단 선택은 교사의 명시적인 출제 지시이므로, 선택한 단의 곱셈·나눗셈이 학년 기본 계산보다 우선합니다.
- 이번 구현은 **학년별 계산 범위의 첫 단계**입니다. 특정 교과서나 국가 성취기준 전체를 충족했다고 표시하지 않습니다. 3~6학년과 시각·측정·도형·자료 등의 개념 문항은 다음 단계에서 검수해 추가합니다.
- 학생의 실명이나 개별 답변을 새로 저장하지 않습니다. 학년 설정만 기존 교사 방 설정에 보관합니다.

## 무엇을 할지 → 왜 → 어떻게 확인할지

| 단계 | 구현 | 이유 | 완료 기준 |
|---|---|---|
| 1 | 교사 방 설정에 학년 기본값·입력 검증 | 기존 방과 안전한 호환성 | 생략 시 1학년, 1·2 허용, 범위 밖 거절 테스트 |
| 2 | 2학년용 100 이내 덧셈·뺄셈 생성 | 실제 문제 난이도가 달라져야 함 | 정답·선택지·중복·시드 다양성 단위 테스트 |
| 3 | 교사 선택 화면과 서버 문제 연결 | 태블릿에서 터치로 설정 | 방 생성·학생 입장·답 제출·화면 테스트, 타입 검사·빌드 |

## 배포 경계

로컬 작업 브랜치에만 반영합니다. `main` 병합, 원격 push, 운영 Vercel·Cloudflare 배포는 하지 않습니다.

## 구현·검증 결과

- 교사 화면에 1·2학년 선택을 추가하고, 단을 고르지 않은 2학년 방에서는 100 이내 덧셈·뺄셈이 출제되도록 연결했습니다.
- 문제 생성 과정에서 초반 12문항 반복을 발견해 규칙을 수정했습니다. 기존 1학년 문제는 그대로 유지합니다.
- 게임 코어 45개, 공유 프로토콜 18개, 실시간 서버 40개, 웹 42개 테스트가 통과했습니다. 웹·실시간 타입 검사와 웹 프로덕션 빌드도 통과했습니다.
- 실제 태블릿에서 학생 2명 이상이 학년별 방을 플레이하는 수동 시험과 운영 배포는 아직 수행하지 않았습니다.
