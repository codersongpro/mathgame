# Bubble Semble 페이즈 3-6: 선택 단의 나눗셈 혼합 출제

## 짧은 요약

교사가 1~19단을 선택한 뒤 ‘나눗셈도 출제’를 켜면, 해당 단의 곱셈과 나누어떨어지는 나눗셈을 번갈아 냅니다. 모든 답은 자연수입니다.

## 범위와 가정

- 나눗셈은 `선택한 단 × 1~19`를 선택한 단으로 나누는 형태입니다. 예: `42 ÷ 7 = ?`.
- 단을 선택하지 않으면 나눗셈 옵션을 켤 수 없습니다. 기본값은 기존 덧셈·뺄셈이며, 구구단 선택만 하면 기존 곱셈 전용입니다.
- 곱셈·나눗셈 문제는 개인 문제와 팀 관문 모두에 적용합니다. 문제/정답은 본인에게만 보내고 팀에는 맞힌 개수만 공유합니다.
- 소수 몫, 나머지, 학년별 문항 구분은 이번 묶음에 포함하지 않습니다.

## 무엇을 할지 → 왜 → 어떻게 확인할지

| 단계 | 구현 | 이유 | 완료 기준 |
|---|---|---|
| 1 | 방 설정에 나눗셈 혼합 여부 검증 | 잘못된 설정으로 방이 열리지 않도록 | 단 없는 나눗셈 거부·기본값 테스트 |
| 2 | 정확히 나누어지는 문제 생성 | 초등 학생의 기본 나눗셈 연습 | 선택한 단과 몫 검증·다양성 테스트 |
| 3 | 교사 체크박스·서버 연결 | 태블릿에서 키보드 없이 설정 | 폼·방 입장·정답 제출 테스트, 타입 검사·빌드 |

## 배포 경계

작업 브랜치에만 반영합니다. 운영 `main`, Vercel, Cloudflare는 변경하지 않습니다.

## 구현·검증 결과

- 선택한 단의 곱셈과 정확히 나누어떨어지는 나눗셈을 번갈아 출제합니다. 단을 고르지 않으면 나눗셈을 켤 수 없습니다.
- 학생 개인 문제, 교사 설정 화면, 실시간 서버 정답 판정까지 연결했습니다.
- 게임 코어 42개, 공유 프로토콜 17개, 실시간 서버 39개, 웹 40개 테스트가 통과했습니다. 웹·실시간 타입 검사와 웹 프로덕션 빌드도 통과했습니다.
- 실제 태블릿 수동 플레이와 운영 배포는 아직 수행하지 않았습니다.
