# Bubble Semble 페이즈 5-2: 3·4학년 기본 계산 선택

## 짧은 요약

교사 방의 학년 선택을 1~4학년으로 확장합니다. 단을 선택하지 않은 방에서 3학년은 1,000 이내, 4학년은 10,000 이내 덧셈·뺄셈을 냅니다.

## 가정과 경계

- 1·2학년 출제 규칙과 기존 방의 1학년 기본값은 변경하지 않습니다.
- 교사가 구구단을 선택하면 학년별 기본 계산보다 선택한 단의 곱셈·나눗셈이 우선합니다.
- 이 단계는 학년별 **기본 계산 범위**만 제공합니다. 모든 학년 성취기준을 충족한다는 표시는 하지 않습니다. 5·6학년과 분수·소수·도형·측정 등의 개념 문항은 후속 단계입니다.
- 정답 선택지 검증 범위는 10,000까지 늘리되 서버가 현재 학생 문제에 제시한 네 선택지에 속하는지 계속 검사합니다.

## 무엇을 할지 → 왜 → 어떻게 확인할지

| 단계 | 구현 | 이유 | 완료 기준 |
|---|---|---|
| 1 | 방 학년 설정과 문제 선택지 범위 검증 | 큰 수의 답도 받을 수 있어야 함 | 1~4 허용·5 이상 거절, 10,000 허용·초과 거절 테스트 |
| 2 | 3·4학년 문제 생성 | 학년 선택이 실제 계산 범위를 바꿈 | 정답·선택지·초반 중복·시드 변화 단위 테스트 |
| 3 | 교사 화면·실시간 서버 연결 | 태블릿에서 터치로 방 생성 | UI와 학생 입장·정답 통합 테스트, 타입 검사·빌드 |

## 배포 경계

작업 브랜치에만 반영합니다. `main` 병합, 원격 push, 운영 배포는 하지 않습니다.

## 구현·검증 결과

- 교사 화면에서 1~4학년을 선택할 수 있고, 구구단을 선택하지 않은 3·4학년 방은 각각 1,000·10,000 이내 계산 문제를 냅니다.
- 큰 수 답안은 최대 10,000까지 형식 검증을 통과하지만, 실시간 서버는 현재 학생에게 제시한 네 선택지에 들어 있는 답만 판정합니다.
- 게임 코어 48개, 공유 프로토콜 18개, 실시간 서버 42개, 웹 44개 테스트가 통과했습니다. 웹·실시간 타입 검사와 웹 프로덕션 빌드도 통과했습니다.
- 실제 태블릿 수동 플레이와 운영 배포는 아직 수행하지 않았습니다.
