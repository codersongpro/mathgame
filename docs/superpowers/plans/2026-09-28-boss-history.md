# Bubble Semble 페이즈 4-1: 교사 보스 기록 이력

## 짧은 요약

교사 모니터에 최근 보스 타임어택 기록 전체를 보여줍니다. 인원이 다른 팀의 기록을 그대로 비교하지 않고, 같은 참가 인원 중 최단 시간을 따로 표시합니다.

## 무엇을 할지 → 왜 → 어떻게 확인할지

| 단계 | 구현 | 이유 | 완료 기준 |
|---|---|---|
| 1 | 기존 `bossRuns` 최대 24건을 최신순 목록으로 표시 | 마지막 기록만 보이는 문제 해결 | 교사 화면 테스트에서 여러 세트의 기록·순서 확인 |
| 2 | 같은 인원 기준 개인 아닌 팀 최고 시간 표시 | 참가 인원 차이를 고려한 성장 확인 | 다른 인원의 빠른 기록이 최고 시간에 섞이지 않는 테스트 |

기록에는 세트 번호·참가 인원·걸린 초만 있으며 학생 이름이나 개별 답안은 추가 저장하지 않습니다. 영구 개인 랭크와 인증·암호화는 별도 페이즈입니다. 운영 배포는 하지 않습니다.

## 구현·검증 결과

- 교사 화면에 최근 24회의 보스 기록을 최신순으로 표시하고, 같은 참가 인원별 최단 시간에 표시를 더했습니다.
- 교사 화면 테스트 5개, 웹 전체 테스트 41개, 웹 타입 검사와 프로덕션 빌드가 통과했습니다.
- 운영 환경에서 실제 여러 세트를 플레이하며 확인하는 작업은 남아 있습니다.
