# Bubble Semble 페이즈 5-4: 1학년 수 비교 문항

## 목표와 경계

- 기존 1학년 기본 덧셈·뺄셈 사이에 `20 이내 수의 크기 비교`를 한 유형 추가한다.
- 문제는 방별 시드와 순서에 따라 달라지고, 네 선택지 중 가장 큰 수 또는 가장 작은 수를 고른다.
- 교사가 구구단을 선택한 경우에는 기존 우선순위를 유지한다. 학생 정보 저장, 교사 설정, 서버 판정 방식은 변경하지 않는다.
- 특정 교과서나 전체 성취기준과의 일치를 주장하지 않는다. 문항 표현은 교사 수동 검수가 필요하다.

## 무엇을 할지 → 왜 → 검증

1. 기존 계산 테스트를 유지하되 새 개념 문항의 출제 순서를 명시한다. 이어서 정답·선택지 범위·중복·시드 재현 테스트를 먼저 작성한다.
2. 문제 생성기에만 분기 하나를 더해 세 문항 중 하나를 수 비교 문제로 만든다. 다른 학년과 구구단 설정을 건드리지 않는다.
3. 게임 코어의 관련 테스트, 타입 검사, 서버의 관련 테스트를 확인한 뒤 로컬 브랜치에 커밋한다.

## 완료 기준

- 1학년 기본 문제에는 덧셈·뺄셈·수 비교가 모두 나오며, 수 비교 정답은 0~20의 네 선택지에 정확히 한 번 들어간다.
- 같은 방 시드와 순서는 재현되고, 다른 시드의 문제는 달라진다.
- 기존 구구단 우선순위와 다른 학년 문제 생성 테스트가 통과한다.

## 구현·검증 결과

- 1학년 기본 문제의 세 문항 중 하나에 20 이내 수 비교를 추가하고, 교사 화면의 학년 안내도 실제 문항군과 맞췄다.
- 문제 생성 16개, 교사 화면 11개, 실시간 서버의 학년 관련 5개 테스트가 통과했다. 게임 코어·웹 타입 검사도 통과했다.
- 실시간 서버 테스트 도중 Wrangler가 샌드박스 밖 로그 파일을 쓰지 못했다는 경고가 있었으나 테스트는 종료 코드 0으로 완료됐다. 실제 태블릿 시험과 운영 배포는 아직 하지 않았다.
