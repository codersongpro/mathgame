# Bubble Semble 페이즈 5-3: 5·6학년 첫 개념 문항군

## 짧은 요약

교사가 5·6학년을 선택할 수 있게 하고, 5학년에는 평균·직사각형 넓이, 6학년에는 백분율·직육면체 부피를 번갈아 출제합니다. 네 선택지는 태블릿에서 터치로 답할 수 있는 자연수입니다.

## 가정과 경계

- 이것은 학년별 콘텐츠를 확장하는 **첫 개념 문항군**입니다. 분수·소수·도형 해석·자료 분석 등 다른 성취기준은 후속 검수·추가가 필요하며, 공식 교육과정 전체를 완료했다고 표시하지 않습니다.
- 평균은 정수 결과가 되는 세 수를, 백분율은 정수 결과가 되는 수와 비율을 생성합니다. 나눗셈의 나머지나 소수 답은 이번 묶음에 넣지 않습니다.
- 교사가 구구단을 선택하면 기존처럼 선택한 단의 곱셈·나눗셈이 학년 기본 문항보다 우선합니다.
- 정답과 개별 선택은 서버가 판정하고 학생 본인 이외에는 공개하지 않습니다. 새 개인정보 저장 기능은 추가하지 않습니다.

## 무엇을 할지 → 왜 → 어떻게 확인할지

| 단계 | 구현 | 이유 | 완료 기준 |
|---|---|---|
| 1 | 방 학년 설정을 1~6으로 확장 | 초등 전 학년에서 방 열기 가능 | 기본 1 유지, 5·6 허용, 범위 밖 거절 테스트 |
| 2 | 평균·넓이·백분율·부피 생성 | 계산을 넘어 개념 적용형 문항 제공 | 4유형의 정답·단위·선택지·초반 중복 검증 |
| 3 | 교사 화면·실시간 서버 연결 | 실제 수업방에서 출제 | 폼·입장·정답 제출 테스트, 타입 검사·빌드 |

## 배포 경계

작업 브랜치에만 반영합니다. `main` 병합, 원격 push, 운영 배포는 하지 않습니다. 실제 학급 적용 전 교사 문항 검수가 필요합니다.

## 구현·검증 결과

- 5학년은 평균·직사각형 넓이, 6학년은 백분율·직육면체 부피를 번갈아 냅니다. 넓이와 부피의 단위를 문제에 표시합니다.
- 학생이 두 문항을 연속으로 풀 수 있고, 제시되지 않은 임의의 큰 숫자는 서버가 거절함을 확인했습니다.
- 게임 코어 51개, 공유 프로토콜 18개, 실시간 서버 44개, 웹 46개 테스트가 통과했습니다. 웹·실시간 타입 검사와 웹 프로덕션 빌드도 통과했습니다.
- 문항의 교육적 적절성에 대한 교사 검수, 실제 태블릿 수동 플레이, 운영 배포는 아직 수행하지 않았습니다.
