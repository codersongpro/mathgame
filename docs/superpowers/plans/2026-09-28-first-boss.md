# Bubble Semble 페이즈 3-3: 첫 보스전 기본 루프 구현 계획

## 짧은 요약

일반 스테이지 3을 클리어하면 같은 방의 모든 학생이 첫 보스 `혼돈의 큐브왕`과 만납니다. 각자의 수학 조각으로 방어막을 해제하고 거품을 맞혀 체력을 줄입니다. 체력이 0이 되면 팀의 클리어 시간을 서버가 기록합니다.

## 이번 묶음의 경계

- 이번에는 **플레이 가능한 보스 기본 루프**를 완성합니다. 3단계에 걸친 공격 패턴, 보정 타임어택 랭크, 다음 난이도 세트는 이어지는 별도 묶음입니다.
- 보스 기본 체력은 6이며 인원별 배율 `1 + 0.55 × (인원 - 1)`로 늘립니다. 방 생성 후 보스 진입 시점 인원을 기준으로 고정합니다.
- 보스전 시작 시 팀 수학 조각을 풀어 방어막을 해제합니다. 그전의 거품은 피해를 주지 않습니다. 해제 뒤 거품 한 개가 닿으면 체력 1을 줄입니다.
- 보스 위치·거품 충돌·방어막·체력·완료 시간은 서버가 판정합니다. 학생이 보스 피해나 좌표를 전송할 수 없습니다.
- 보스 시간은 시작부터 클리어까지 서버 틱으로 잽니다. 방이 비어 서버 틱이 멈춘 시간은 제외합니다. 결과에는 참여 인원과 실제 플레이 시간을 남기되 영구 랭킹은 아직 만들지 않습니다.
- 임시 픽셀 큐브 그래픽과 태블릿용 체력·시간 HUD를 사용합니다. 학생 실명이나 개인 답은 기록하지 않습니다.

| 단계 | 구현 | 이유 | 완료 기준 |
|---|---|---|---|
| 1. 순수 보스 규칙 | 인원별 체력, 거품 충돌, 방어막 판정 | 서버·클라이언트가 같은 값을 계산하고 위조를 막음 | 1·2·10인 체력, 방어막·명중·빗나감 테스트 |

## 배포 경계

운영 `main`과 Vercel·Cloudflare는 변경하지 않습니다. 배포 전 2인 태블릿 실기 시험이 필요합니다.

## 구현·검증 결과 (2026-09-28)

- 3단계 클리어 후 같은 방에서 큐브왕 보스전으로 이동하고, 팀 문제 조각을 풀어 방어막을 해제합니다.
- 서버가 인원별 체력, 거품 충돌, 체력 감소와 클리어 시간을 판정하고 교사 현황에 팀 결과를 표시합니다.
- 2인 공동 입장과 1인 보스 클리어의 실시간 통합 테스트를 통과했습니다. 공용 형식 14개, 게임 규칙 37개, 실시간 서버 37개, 웹 40개 테스트 및 타입 검사·웹 빌드·Worker 드라이런이 통과했습니다.
- 실제 태블릿 실기 시험은 아직 하지 않았습니다. 보스의 세부 공격 패턴, 인원 보정 기록, 다음 난이도 세트는 다음 묶음으로 분리합니다.
