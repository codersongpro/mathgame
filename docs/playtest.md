# Bubble Semble 시험 플레이

1. Vercel에 새 버전이 배포된 뒤 `/teacher` 페이지를 엽니다.
2. 교사 접속키를 입력합니다. 목표 시간·점수는 비워두면 기본값이 적용됩니다.
3. **시험 플레이 시작**을 누릅니다. 새 6자리 방이 자동으로 만들어지고 `교사테스트`로 실제 게임에 바로 입장합니다.
4. 태블릿 화면의 이동·점프·거품·팡 버튼과 수학 문제를 시험합니다.
5. 다른 기기와 함께 시험하려면 **친구 입장 링크 복사**를 눌러 해당 기기에서 엽니다. 상대방은 방 번호를 입력하지 않습니다. 링크를 복사할 때마다 임시 별명이 달라집니다. 정원은 10명입니다.
6. **교사 모니터**로 돌아가 팀 점수와 스테이지를 확인합니다. 모니터는 방을 만든 교사 브라우저의 보호된 쿠키가 있어야 열립니다.

시험 플레이도 실제 실시간 서버와 같은 규칙을 사용합니다. 방은 4시간 뒤 만료됩니다. 링크에는 공개 입장 코드만 있으며 교사 접속키·모니터 토큰은 포함되지 않습니다. 학생 실명이나 개인정보를 시험 별명으로 쓰지 마세요.

현재 플레이 가능한 범위는 일반 스테이지 1→2입니다. 피격·탈락, 3스테이지·보스전은 아직 구현되지 않았습니다.
